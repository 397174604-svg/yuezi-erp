## MySQL 5.7 落库

迁移文件按职责拆分为：

- 字典：`sys_dictionary_types`、`sys_dictionary_items`
- 菜单按钮：`sys_legacy_menus`、`sys_legacy_buttons`
- 权限：`sys_role_resource_grants`、`sys_role_department_scopes`
- 参数：`sys_parameters`、`sys_warning_parameters`
- 审批：`sys_approval_categories`、`sys_approval_processes`
- 消息：`sys_sms_nodes`、`sys_sms_recipients`
- 模板任务：`sys_report_templates`、`sys_message_templates`、`sys_plan_tasks`
- 返利：`sys_rebate_profiles`、`sys_rebate_category_settings`
- 会所资料：`sys_club_profiles`
- 导入批次：`sys_config_import_runs`

旧系统 ID 单独保留，导入时先建立旧 ID 到新主键的映射，再写父子关系和角色授权，避免直接把旧 ID 当新系统主键。
