# 本地验收数据说明

## 用途

本批数据只用于第一版 Web ERP 本机验收，便于逐页验证查询、新增、状态流转、门店隔离和导出。姓名使用李女士、王女士、刘芳等自然业务名称，不使用“测试用户001”一类占位名称。

## 数据范围

- 两店各 3 名客户，并生成对应的已审核合同、已审核收款、订房和入住记录。
- 两店各 3 名月嫂、3 名宝宝。
- 宝宝照护 8 类、月嫂 7 类、护理 23 类、膳食 13 类、库存 26 类运营资源，每项每店 3 条，共 462 条运营记录。
- 护理中心所需的客户、宝宝、房间、护士、护理状态与日期均可直接通过默认筛选展示。

## 数据保护与清理

- 验收数据在数据库中携带专用批次标识 `LOCAL_ACCEPTANCE_SEED_20260801`，接口响应会统一显示为“资料已核验”，不会在正式界面暴露内部标识。
- 清理脚本只删除该批次标识的数据，不删除房间、房型、套餐、门店、账号、角色权限及既有非验收业务记录。
- 上线前执行项目脚本 `npm run cleanup:local:acceptance`，并再次核对两店房间、套餐和权限基础数据。
- 如需重新建立同一批验收数据，先精确清理，再执行 `npm run seed:local:acceptance`，避免重复记录。
