# ERP 104 项当前缺口复核（2026-08-01）

## 复核范围与结论

- 需求基准：`月子会所功能开发清单-按端拆分-128项-2026.xlsx` 的“ERP后台（Web）”工作表。
- 代码基准：`src/config/erp-feature-registry.js`、`src/router/index.js`、各业务工作台配置与现有接口调用。
- 本次仅做静态只读核查；未修改业务页面、接口、数据库、F018 客房房态或 F019 智能排房。
- 注册表共 **104 项且编号唯一**，其中 **P0 62 项**。校验脚本通过，只能证明“功能已登记并分配入口”，不能证明接口和业务闭环已完成。

| F089 储值卡/折扣卡/微信卡包 | `finance-workbench` 回退到“收款管理” | 不属于普通收款台账，当前未知标题默认成收款管理 | 映射会员卡资产/卡包接入页；第三方卡包未配置时保留申请、失败和重试记录 |
| F108 审批流引擎 | `approval-workbench` 的默认空配置 | 当前只有 F010“审批中台”配置；F108 命中 fallback，缺流程定义、节点、角色和版本能力 | 独立为流程设计/发布/停用/版本回滚页，不能等同审批待办 |
| F086 在线预约看板 | 实际回退 F017“预约与排班”配置 | 路由先将括号内容删成“在线预约看板”，而 `schedule-pages.js` 仍以完整名称作为键，导致配置不命中 | 以功能编号或稳定 key 取配置；保留在线渠道、技师、时段容量的独立看板 |
| F058 门店与渠道、F093 连锁多门店管理 | `store-workbench` 均落入 `UNAVAILABLE` 相同空态 | 路由删掉括号内容后，与 `pageDefinitions` 的完整标题不匹配；两项定义虽然存在，但当前入口无法命中 | 增加稳定别名或改用功能编号；F058 处理门店/渠道/转店，F093 处理会员共享和资金归集 |
| F061 系统设置、F079 历史数据迁移、F098 品牌定制 | `system-workbench` 均复用第一项系统定义的字段结构 | 三个产品名不在 `systemPageConfigs` 中，fallback 复制首个系统配置，仅替换标题 | F061 映射系统参数设置；F079 建立导入预检/映射/执行/回滚日志；F098 建立 Logo、主题、域名发布与回滚 |

根因证据：`src/router/index.js` 的 `cleanMenuTitle()` 会移除括号内容；`createPageRoute()` 又把清理后的标题作为 `configTitle`。多个工作台仍用完整标题作为配置键，未知键则回退默认页。后续应优先以 **功能编号或固定资源 key** 映射页面，避免再依赖展示名称。

## 发布优先级建议

1. **先修入口错配**：F003、F058、F061、F086。它们是 P0 且当前用户点击即看到错误/空页面。
2. **禁止未知标题回退业务页**：sales、finance、approval、system 等工作台遇到未知配置时应显示明确待接入页，不能回退合同、收款或部门管理。
3. **补 P0 硬阻断接口**：F010、F025、F027、F038、F039、F041、F044-F049、F051、F053-F055。
4. **完成部分闭环和口径**：F006、F008、F012、F015、F016、F040、F050、F052、F056-F060。
5. 每项合并前至少验证：正确角色可进入、门店范围正确、查询、详情、新增/编辑或业务处理、状态回写、明确错误提示、审计；有台账的功能验证导出。
