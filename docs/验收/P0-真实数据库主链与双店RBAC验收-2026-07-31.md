## 4. 双店 P0 主链

中心店和黄河路各执行一遍：

1. 本店销售创建客户。
2. 本店销售创建合同。
3. 异店店长审核合同返回 HTTP 403；本店店长审核通过。
4. 本店财务登记收款 30,000 元。
5. 异店财务审核收款返回 HTTP 403；本店财务审核通过。
6. 本店店长选择无冲突空闲房并订房。
7. 异店店长办理入住返回 HTTP 403；本店店长办理入住成功。
8. 本店护理可查看客户，但财务审核、入住写操作均被拒绝。
9. 直接查询 MySQL，确认客户/订房/房间为已入住，合同和收款已审核，
   合同已收款为 30,000 元。

结果：

| 门店 | 最终状态 | 跨店业务拒绝 |
| --- | --- | --- |
| 奇德芬芳·建设路店（中心店） | 已入住 | 3 次 HTTP 403 |
| 奇德芬芳·黄河路店 | 已入住 | 3 次 HTTP 403 |

第一次执行因验收脚本在读取房间快照后保留 MySQL `REPEATABLE READ` 事务，最终
查询看不到其他 API 连接随后提交的数据，报告 `incomplete MySQL relationship`。
该次测试的自动清理和外层清理均成功。脚本在快照读取后显式结束只读事务后，第二次
双店完整验收通过。
