# 奇德芬芳月子会所 ERP 使用说明

> 本说明只介绍当前 Web ERP 的实际使用方法。
> 本地测试地址：`http://127.0.0.1:9527`
> 正式上线后请使用公司提供的正式网址和个人账号。

## 1. 登录系统

1. 打开 ERP 地址。
2. 输入系统管理员分配的账号和密码。
3. 点击“登录”。
4. 登录后先查看右上角“当前门店”，确认正在操作中心广场旗舰店还是黄河路轻奢店。

本地联调账号为 `admin`，密码为 `admin123`。该账号只用于本机测试，正式上线前必须停用默认密码并改用个人账号。

## 2. 顶栏常用功能

### 切换门店

1. 点击右上角“当前门店”。
2. 选择中心广场旗舰店或黄河路轻奢店。
3. 系统会同步刷新首页、客户签约、预约、房态和智能排房数据。

进行建档、签合同、收款或订房前必须先确认门店，避免把业务录入到错误门店。

### 搜索客户或房间

1. 点击顶栏搜索框。
2. 输入客户姓名、手机号、客户编号或房间号。
3. 点击搜索结果，可直接进入对应客户办理页面。

### 查看通知

1. 点击顶栏铃铛。
2. 可查看合同待审核、收款待审核、待入住、预约待执行和预产期提醒。
3. 点击通知可进入对应业务页面。
4. 已处理的通知可标记为已读，也可使用“全部已读”。

## 3. 系统首页

进入“系统首页”后：

1. 选择门店。
2. 选择今天、本周、本月、本季度或本年度。
3. 查看客户、合同、收款、入住、房态、待办和预警数据。
4. 点击指标卡或待办项，可跳转到对应业务页面。

首页数据为经营辅助信息，办理业务仍应进入对应业务模块核对明细。

## 4. 客户签约与入住完整流程

菜单入口：`客户管理 → 客户签约办理`

系统按以下顺序办理：

`客户建档 → 合同审核 → 收款审核 → 订房 → 入住`

### 第一步：客户建档

1. 打开“1 客户建档”。
2. 选择门店。
3. 填写客户姓名、手机号和微信号。
4. 选择客户阶段、意向等级、客户来源、业务员和客户类型。
5. 如果客户为“孕期待产”，填写今天或未来的预产期。
6. 如果客户为“已分娩”，填写今天或过去的分娩日期。
7. 填写备注。
8. 点击“保存并签合同”。

手机号重复时，先核对是否已经建档，不要重复创建客户。

### 第二步：签订并审核合同

1. 打开“2 合同签订”。
2. 选择门店和客户。
3. 选择合同类型和套餐。
4. 核对参考价格、活动价、成交金额和入住天数。
5. 选择预住日期和预离日期。
6. 核对签单日期。
7. 如果补录历史合同，填写补录原因。
8. 点击“保存合同”。
9. 具有审核权限的人员在合同列表点击“审核”。

套餐天数必须与入住区间一致。未审核合同不能进入正式收款和订房流程。

### 第三步：登记并审核收款

1. 打开“3 收款审核”。
2. 选择门店和已审核合同。
3. 选择收款类型。
4. 输入收款金额。
5. 选择支付方式和收款时间。
6. 其他收款或历史补录必须在备注中写明原因。
7. 点击“登记收款”。
8. 具有财务审核权限的人员在收款列表点击“审核”。

收款审核通过后才计入已入账金额。登记金额不能超过合同当前可收金额。

### 第四步：办理订房

1. 打开“4 订房入住”。
2. 选择门店。
3. 选择满足订房条件的合同。
4. 选择同门店的可用房间。
5. 选择入住日期和离店日期。
6. 点击“办理订房”。

可以订房的合同必须同时满足：

- 合同已审核；
- 至少有一笔收款已审核入账；
- 当前合同没有其他有效订房；
- 合同、客户和房间属于同一门店；
- 入住日期与其他客户不冲突。

### 第五步：办理入住

1. 在订房列表找到客户。
2. 核对客户、合同、房间和入住日期。
3. 点击“办理入住”。
4. 确认后，客户状态、订房状态和房态会同步更新。

入住前如果需要更换房间，应先核对新房间日期是否可用，并记录换房原因。

## 5. 智能排房

菜单入口：`客房管理 → 智能排房`

1. 选择门店，系统会自动加载该门店的套餐和房间。
2. 选择客户或合同。
3. 选择入住套餐，系统自动带出入住天数。
4. 选择入住日期。
5. 房型可以不选；不选时系统会在本店全部可用房间中推荐。
6. 如客户明确要求，可再选择房型、楼层或朝向。
7. 点击查询，查看推荐方案。
8. 优先选择“全程不换房”方案。
9. 没有连续空房时，可查看同房型换房或跨房型换房方案。
10. 特殊情况可人工指定同门店、日期无冲突的房间。

维修、消毒、内部占用和保留中的房间不会进入推荐结果。最终确认前应再次核对客户合同、入住日期和房间状态。

## 6. 房态图

菜单入口：`客房管理 → 房态图`

1. 先选择门店。
2. 按房号、房型、楼层、朝向或状态筛选。
3. 查看空闲、已预订、已入住、维修、消毒、内部占用和保留状态。
4. 点击房间查看客户和占用日期。
5. 办理订房、入住或退房后刷新房态图，确认状态已经同步。

中心店和黄河路店房间独立显示，不能跨店选择房间。

## 7. 服务预约

菜单入口：`产康管理 → 服务预约列表`

1. 选择门店。
2. 选择预约类型、客户和服务项目。
3. 选择执行人员、预约日期和时间段。
4. 填写备注。
5. 保存预约。
6. 到店后按实际情况更新为已到店、执行中、已完成或取消。

同一执行人员或同一资源在重叠时间已有预约时，系统会阻止重复预约。

## 8. 会员资产

菜单入口：`客户管理 → 会员资产`

### 次卡核销

1. 找到客户次卡。
2. 点击“核销一次”。
3. 核对客户、卡项和剩余次数。
4. 确认核销。

### 储值卡扣款

1. 找到客户储值卡。
2. 点击“余额扣款”。
3. 输入扣款金额和用途。
4. 确认扣款。
5. 核对余额和资产流水。

核销和扣款完成后不能直接修改原记录；如操作错误，应走退款或冲正流程并保留原因。

## 9. 常见问题

### 页面没有数据

先检查右上角当前门店，再点击页面“刷新”。

### 合同无法收款

检查合同是否已审核，以及合同是否还有可收金额。

### 合同无法订房

检查合同是否已审核、是否有已审核入账收款、是否已有有效订房，以及房间是否属于当前门店。

### 智能排房没有推荐结果

检查门店、入住日期、入住天数和房型筛选；必要时清空房型筛选后重新查询。

### 出现 404 或空白页面

记录左侧菜单名称和浏览器地址，刷新一次；仍未恢复时联系系统管理员，不要重复提交业务。

## 10. 退出系统

1. 点击右上角个人账号。
2. 点击“退出登录”。
3. 公共电脑使用结束后必须退出，不要只关闭浏览器。

## 11. 当前多端说明

- Web ERP 管理端：当前主要交付系统，本地端口为 `9527`。
- 后端 API：供正式数据库和多端共用，默认配置端口为 `3000`；部署后通常由正式域名反向代理，不直接让普通用户输入端口。
- 员工端：代码位于 `apps/staff`，可构建 H5 或微信小程序。
- 宝妈端：代码位于 `apps/mom`，可构建 H5 或微信小程序。
- `apps/admin` 的 `5174` 是仓库中的另一套 Vue3 管理后台开发入口，不是当前 `9527` Web ERP 的正式访问入口。

本轮上线范围为 Web ERP。员工端和宝妈端需要独立完成微信登录、身份绑定、接口权限、消息、隐私、真机测试和微信审核后才能正式对外使用。
