# 月子会所 ERP 老板使用说明

## 每日先看什么

进入“总部驾驶舱”，在右上角选择门店或“全部门店”。这里用于看客户新增、合同、收款、入住、房态和待办；明细办理请进入左侧对应业务模块。

## 签约到入住

1. 打开“客户签约办理”，在“客户建档”先选门店，再填写客户资料并保存。
2. 打开“合同签订”，选择客户与套餐。套餐会带出入住天数、参考价和适用房型；成交金额由业务人员按实际成交填写。
3. 在合同列表审核合同，再到“收款审核”登记并审核收款。
4. 在“订房入住”选择已审核且已入账的合同；从系统可用房间中选择房号，选择入住日期后办理订房。
5. 入住后，由护理、膳食、产康等模块按门店记录服务；离店时在客房/结算相关功能完成退房与结算。

## 两店规则

- 普通客户、合同、收款、房间和员工排班按发生门店查询与办理。
- 会员主档可跨门店查询；会员卡消费仍应保留发生门店。
- 黄河路：先选门店，再选套餐，套餐决定可用房型和入住天数。
- 中心店：当前未配置套餐主数据时，不强制选套餐，按实际房型和房间办理。

## 常用管理

- **房态与排房**：先选门店，按房型、楼层和日期查看空房；不要手工输入房号代替选择。
- **员工与权限**：在系统设置维护员工账号、所属门店、部门与角色；新增账号后再按角色分配菜单和数据范围。
- **报表**：先选门店和日期范围，查询后再导出。汇总使用“全部门店”，业务录入必须选择具体门店。
