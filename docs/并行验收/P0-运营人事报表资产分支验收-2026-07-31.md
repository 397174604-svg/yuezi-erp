## 4. 本分支实际代码修复

### F059 会员资产

- 新增迁移 `V20260731_024__member_asset_store_transactions.sql`：
  - `member_asset_accounts`：租户内客户共享余额账户；
  - `member_asset_cards`：套餐卡/次卡/储值卡；
  - `member_asset_transactions`：不可省略发生门店的交易流水。
- 新增正式 API：
  - `GET /vue-element-admin/erp/assets/options`
  - `GET /vue-element-admin/erp/assets/overview`
  - `GET /vue-element-admin/erp/assets/cards`
  - `GET /vue-element-admin/erp/assets/accounts`
  - `POST /vue-element-admin/erp/assets/cards`
  - `POST /vue-element-admin/erp/assets/cards/{id}/consume`
  - `POST /vue-element-admin/erp/assets/accounts/{id}/top-up`
  - `POST /vue-element-admin/erp/assets/accounts/{id}/deduct`
- 前端发卡、充值、扣款、核销都增加“发生门店”必选；服务端二次校验，不能靠篡改请求越权。
- 支付和外部消息接口在未配置时明确返回“未配置”，不伪造成功。

### F056 数据报表

- 报表查询不再在接口异常或空结果时生成 12 条演示数据。
- 页面改为显示 MySQL 真实查询状态。
- 新增“导出当前结果”CSV。
- 报表 API 接受门店 ID/名称并在账号授权门店内收窄查询。
