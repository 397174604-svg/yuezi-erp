# 门店隔离与会员共享规则

生效日期：2026-07-31。适用于中心广场旗舰店、黄河路轻奢店及后续新增门店。

## 1. 统一原则

1. **先选门店，再选业务主数据。** 新建客户、合同、预约、订房、入住、服务、采购、库存、财务单据时，必须先选择一个具体门店；选择后才加载该门店可用的员工、套餐版本、房型、房间、排班和库存。
2. **“全部门店”只用于汇总查询。** 管理员可在顶部选择“全部门店”查看汇总，但新增、保存、审批和扣减操作不得写入“全部门店”，必须落到一个具体门店。
3. **跨店不可误选。** 更换门店时，已选且不属于新门店的客户、套餐、房间、员工、合同等字段必须清空，并提示重新选择。
4. **业务单据保存门店快照。** 合同、收款、订房、入住、服务执行、库存流水、储值/消费流水都要保存发生门店，后续统计按发生门店归集。

## 2. 会员与普通客户

| 对象 | 查询范围 | 新建/业务归属 |
| --- | --- | --- |
| 普通客户、线索、合同、预约、订房、入住 | 当前选中的门店 | 新建客户必须归属一个门店；后续主链只读取该门店客户和合同 |
| 会员主档、会员卡身份 | 全门店共享 | 同一手机号/会员号只有一个会员主档，不因切换门店而隐藏 |
| 次卡、储值卡、积分、消费、核销、充值 | 可跨门店查会员，但流水按发生门店 | 每笔操作必须选择或继承具体发生门店，保存后不可变更 |

## 3. 套餐与房间

1. 套餐选择值不是自由文本，而是已启用的 **套餐版本 + 门店 + 推荐房型 + 天数 + 价格规则**。
2. 合同保存时冻结该价格规则，防止以后调整价目表影响历史合同。
3. 套餐只决定合同价格版本和推荐房型；除非甲方后续确认“强绑定”，订房仍可在本门店可用房间中人工选择或由智能排房推荐。跨房型/换房产生的差价和审批规则另行确认。
4. 房间号必须由当前门店可用房间列表选择，不允许自由输入。

## 4. 本轮验收点

- 在中心店选择套餐时，不显示黄河路套餐；反之亦然。
- 切换门店后，先前选中的套餐、房间、业务员若不属于当前店，自动清空。
- 普通客户列表随当前门店变化；会员主档搜索在任意门店下均可查到同一会员。
- 会员资产流水、储值/消费/核销记录包含“发生门店”。
